## Known limits of this report

- **A translated page is not checked for completeness.** A page that exists in a locale
  counts as translated even if half its body is still English.
- **Staleness is measured by commit date**, so a formatting-only commit on the English
  page marks the translation stale. Read it as "worth a look", not "definitely wrong".
- **The `pt` locale inherits Docusaurus's Brazilian theme strings.** Docusaurus has no
  bundle for a bare `pt`, and its `pt-PT` bundle is largely still English, so the pt-BR
  one is used. The chrome on the European Portuguese site therefore reads Brazilian in
  places. Overriding a string in `i18n/pt/code.json` wins over the bundle.
