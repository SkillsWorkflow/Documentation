# Using workspaces

A workspace is a configurable view built on the platform's own data. Workspaces are reached from the **Workspaces** menu, and most documents in Skills Workflow can also carry their own workspaces alongside their Feed, Info and Files sections.

The articles in this area each cover one of the workspaces that ships with the platform.

## Availability

Which workspaces a person sees depends on the workspaces configured for the tenant and on that person's permissions. A document only offers workspaces if its own document type enables them.
