The Quotes tab can be used from the keyboard alone. On macOS, use `⌘` in place of `Ctrl`.

## In the grid

| Keys | What they do |
|---|---|
| `↑` `↓` `←` `→` `Tab` | Move |
| Type, or `Enter` / `F2` | Edit |
| `Enter` | Keep the value and go down |
| `Shift`+`Enter` | Edit the description in a larger box |
| `Esc` | Cancel |
| `Delete` | Clear the cell, or the selected cells |
| `Shift`+`↑` `↓` `←` `→` | Select several cells (or `Shift`+click) |
| `Ctrl`+`C` / `V` | Copy, paste. Also blocks from Excel. Pasting into empty rows adds lines |
| `Ctrl`+`D` | Fill down from the first selected row, or from the row above |
| `Ctrl`+`Backspace` | Remove or restore the row, or the selected rows |
| `Ctrl`+`S` | Save the quote |

## Rows and deliverables

| Keys | What they do |
|---|---|
| `Alt`+`C` / `V` | Copy the selected rows, or paste them as new rows. Also in the WebApp |
| `Ctrl`+`Shift`+`↑` `↓` | Move the deliverable or line up or down |
| `Alt`+`Enter` | Open a service's buy conditions |
| `Alt`+`↓` / `↑` | Open or close the details |
| `Alt`+`Shift`+`↓` / `↑` | Expand or collapse all |
| `Alt`+`0` `1` `2` `3` | Show all details, or only resources, services or expenses. Again to hide them |
| `Alt`+`B` | Go to the billing plan. Again to hide it |
| `Alt`+`A` | Show only the approved deliverables, or all |

## In a list

A list opens as you edit. Type to filter it. In typology groups, any part of the role, the department or the company matches. Use `↑` and `↓` to choose, and `Enter` to pick and go down.

| Keys | What they do |
|---|---|
| `Alt`+`↓` | Open or close the list |
| `Ctrl`+`Enter` | In the typology group list, tick several. `Enter` then adds them all |
