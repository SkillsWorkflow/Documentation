## Data Protection & Privacy

We apply strong safeguards to protect all personal and business-critical data.

- **Encryption:**  
  All data is encrypted in transit using TLS 1.2+ and at rest with AES-256.

- **Data Residency:**  
  All data is hosted in secure, enterprise-grade data centers within [European Union / United States].

- **Privacy:**  
  We comply with GDPR and offer full access, portability and deletion tools to users.  
  [View our Privacy Policy](https://www.skillsworkflow.com/privacy-policy)

## Infrastructure & Availability

We use modern cloud infrastructure and robust operational practices to maintain system availability and integrity.

- Hosted on Microsoft Azure
- High availability with auto-scaling, load balancing and data redundancy
- Daily backups and disaster recovery plan
- 24/7 monitoring and alerting  
  [Check live uptime status](status.md)

---

## Access Controls & Authentication

Security starts with access management and identity control.

- Role-Based Access Control (RBAC)
- Single Sign-On (SSO) supported
- Strict internal security policies for system access
- Session expiration and protection against XSS, CSRF and brute-force attacks
