### Description

The Custom Tables API allows you to programmatically create, read, update, and delete data in user-defined custom tables.
Custom tables extend the Skills Workflow data model with additional, tenant-specific tables for storing structured data.

:::tip
If you are working inside Skills Workflow workspaces or automations, prefer using the **SDK methods** (`SW.Document.CustomTable.*`) documented in the [SDK Reference](/docs/sdk/document/customTable) instead of calling the API directly.
:::
