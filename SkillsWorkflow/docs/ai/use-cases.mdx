Each one below is a real scenario for the [AI Assistant](/docs/ai/ai-assistant): the prompt to type in the chat, and the outcome to check for — not just a general capability.

## Create a Job Using a Briefing Template

**Overview**

Create a new job using the [Document Agent](/docs/ai/agents/document-agent) and automatically generate its brief based on the briefing template configured for the selected Job Type.

**Scenario**

A project manager needs to create a new campaign job. By providing the campaign details to the Document Agent, the system creates the job and generates a brief following the structure defined in the Job Type's briefing template.

**Example prompt**

```
Create a new job for the client Nike with the following details:

- Job Type: Digital Campaign
- Job Title: Nike Summer Campaign 2026
- Priority: High
- Description: Develop a digital campaign to promote Nike's summer collection.

Generate the job brief using the briefing template configured for this Job Type.
```

**Expected outcome**

- A new job is created with the specified information.
- The correct Job Type is selected.
- The job brief follows the briefing template configured for that Job Type.
- The generated brief includes the relevant information provided in the prompt.

## Check Burn Without a Dashboard

**Overview**

Compare contracted hours against hours actually logged, and cost against income, straight from your own reports — no workspace to open first.

**Scenario**

An account manager wants to check burn on a retainer before a client call, without navigating to a workspace to find the right report.

**Example prompt**

```
Compare contracted vs. logged hours on the Northwind retainer this month.
```

**Expected outcome**

- The assistant resolves the client or project named in the prompt.
- It answers from one of your tenant's own data extraction reports — the same figures behind your dashboards.
- The result is rendered as a chart with a table beside it.

:::note
Answering from your reports is a capability an agent is granted, not one tied to a single named agent — see [Tools · Your data](/docs/ai/ai-tools#your-data). If the agent you're on says it can't run the query, ask whoever set up your AI which one has this switched on.
:::

## Cover Several Accounts, Not Just One

**Overview**

Ask for a client portal by name and get it built and published — then ask for the next one, in the same conversation.

**Scenario**

An account lead manages several retained clients and wants each one to have its own status page, without building them one by one through a form.

**Example prompt**

```
Build a status portal for Northwind. Then build the same one for Acme, and for Delta.
```

**Expected outcome**

- A separate portal is generated for each client named.
- Each portal reads that client's own live data through their own permissions.
- Each portal is published at its own address.

See [Client Portals](/docs/ai/ai-portals) for how a portal is published, and what to check before handing the link to a client.

## See What's Critical Across Your Accounts

**Overview**

Build a dashboard that surfaces overruns, risks and pending approvals across every client you manage, not just one at a time.

**Scenario**

A studio lead wants one view of what needs attention across every account, instead of checking each client's workspace in turn.

**Example prompt**

```
Build me a dashboard of critical activity across all my accounts — overruns, risks and pending approvals.
```

**Expected outcome**

- The Workspace Agent proposes a dashboard covering every account, not a single client.
- The proposal surfaces overruns, risks and pending approvals.
- Nothing is saved until the proposal is reviewed and applied.

See [Workspace Agent](/docs/ai/agents/workspace-agent) for how a workspace change is built and applied.

## Ask About a Client's Projects and Tasks

**Overview**

Search across a client's jobs, deliverables and tasks and get a straight answer, without opening each one.

**Scenario**

A project manager needs a quick, accurate answer about what's open on a client's account, without opening every job to check.

**Example prompt**

```
What tasks are open on the Northwind account right now?
```

**Expected outcome**

- The assistant searches across that client's jobs, deliverables and other documents.
- It answers directly, naming what is open.
- Clicking a result opens that document.

See [Document Agent](/docs/ai/agents/document-agent) for the full list of document types it can search.
