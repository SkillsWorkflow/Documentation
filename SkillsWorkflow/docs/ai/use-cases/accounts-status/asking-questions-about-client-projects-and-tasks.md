## Overview

Answer questions about projects and tasks across client accounts, providing a consolidated view of progress, responsibilities, deadlines, and outstanding work.

## Example prompt

```
Give me an overview of the current projects and outstanding tasks for [Client / Client List]. Include project status, task progress, overdue activities, upcoming deadlines, and responsible resources. Highlight the main issues and pending actions.
```

## Expected outcome

A consolidated overview of projects and outstanding tasks across the selected client accounts, including progress, overdue activities, upcoming deadlines, responsible resources, and pending actions.
