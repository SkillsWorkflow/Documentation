## Overview

Provide a consolidated overview of multiple client portals, enabling users to monitor the status of several accounts from a single view.

## Example prompt

```
Give me a consolidated overview of the portals for [Client List]. Summarize the status of each client's projects, outstanding requests, risks, and critical issues. Highlight the accounts requiring attention and provide links to the relevant client portals where available.
```

## Expected outcome

A consolidated overview of multiple client portals, showing each client's project status, outstanding requests, risks, and critical issues, with links to the relevant portals where available.
