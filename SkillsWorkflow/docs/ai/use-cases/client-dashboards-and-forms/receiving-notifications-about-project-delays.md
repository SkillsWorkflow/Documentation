## Overview

Identify project delays and schedule-related issues that require attention, including affected projects, milestones, and expected impacts.

:::info[What to ask]
Show me the project delays and schedule-related issues affecting [Client / Projects]. Identify delayed milestones, overdue tasks, affected deliverables, and expected impacts on project timelines. Include the current status and any available explanation for each delay.
:::

:::tip[What you get back]
A list of project delays and schedule-related issues, identifying affected milestones, tasks, deliverables, expected impacts, and available explanations for each delay.
:::
