## Overview

Start a discussion about a resource overrun notification by reviewing the available context, including comments, replies, descriptions, and attached files.

## Example prompt

```
Review the notification about the resource overrun in [Project / Resource]. Analyze the notification details, comments, replies, descriptions, and attached files to understand the situation. Summarize the likely causes and start a discussion with the relevant context, asking for clarification on the overrun and possible next steps.
```

## Expected outcome

A contextual summary of the resource overrun, incorporating the available notification details, comments, replies, descriptions, and attachments, together with a discussion initiated to clarify the cause and possible next steps.
