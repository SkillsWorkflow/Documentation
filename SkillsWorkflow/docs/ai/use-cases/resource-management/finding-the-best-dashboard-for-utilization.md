## Overview

Identify the most suitable dashboard for monitoring resource utilization, including workload distribution and capacity usage.

:::info[What to ask]
What is the best dashboard to monitor resource utilization across [Team / Department / Period]? Identify the most relevant dashboard and explain how it helps monitor workload, capacity usage, and resource utilization.
:::

:::tip[What you get back]
The most relevant dashboard for monitoring resource utilization, with an explanation of how it presents workload distribution and capacity usage, and a link to the dashboard where available.
:::
