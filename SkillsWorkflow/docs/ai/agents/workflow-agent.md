## What it helps with

The Workflow Assistant helps you review and change how documents move through a workflow.

It is useful for tasks such as:

- reviewing an existing workflow
- adding or changing stages
- creating transitions between stages
- adjusting approval paths
- updating who can perform a transition
- changing reasons or actions linked to a transition

## When to use it

Use this assistant when your request is about the setup of the workflow itself.

Good examples include:

- checking how a document type moves from draft to approval
- adding a new stage
- creating a new transition
- limiting a transition to a role or team
- reviewing the current workflow before making changes

## Example requests

- `Show me the workflow for Deliverables`
- `Create a new stage called Under Validation`
- `Add a transition from Draft to Approved`
- `Restrict this transition to managers`
- `Show me which actions are configured on this transition`

## What to have ready

- the workflow or document type name
- the stage names you want to review or change
- the change you want to make
- the role or team involved, if access matters
- any approval or rejection rule you want to add

## When not to use it

- If you want to create or update a document, use the [Document Assistant](document-agent.md).
- If you want help rewriting text, use the [Writing Assistant](writing-agent.md).
- If you want to change a workspace or dashboard, use the [Workspace Assistant](workspace-agent.md).

## What to expect

The assistant will usually review the current workflow first and then guide you through the change. For larger changes, it may work step by step so each part stays clear and correct.
