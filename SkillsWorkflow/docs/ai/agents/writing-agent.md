## What it helps with

The Writing Assistant helps you improve text.

It is useful for tasks such as:

- rewriting a message
- improving grammar
- making text shorter
- making text clearer
- changing tone
- polishing content for professional use

## When to use it

Use this assistant when you want better wording, not a platform action.

Good examples include:

- improving an email before sending it
- turning notes into a clear summary
- making instructions shorter and easier to read
- changing the tone of a message
- checking grammar and style

## Example requests

- `Rewrite this email in a friendlier tone`
- `Make this paragraph more concise`
- `Proofread this message`
- `Turn these notes into a polished summary`
- `Make this sound more professional`

## What to have ready

- the text you want to improve
- the tone you want, if you have one in mind
- the audience, if it matters
- any length or style preference

## When not to use it

- If you want to create or update a document in the platform, use the [Document Assistant](document-agent.md).
- If you want to change workflow setup, use the [Workflow Assistant](workflow-agent.md).
- If you want to edit a workspace or dashboard, use the [Workspace Assistant](workspace-agent.md).

## What to expect

This assistant is designed to be simple. In most cases, you can paste the text, say what you want to improve, and get a ready-to-use result.
