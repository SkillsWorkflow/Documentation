The Writing Agent works on text. Give it something you have written and say what is wrong with it — too long, too blunt, in the wrong language, not clear enough — and it gives the text back changed.

It is also the agent behind [AI Actions](/docs/ai/ai-actions), the wand button in every rich text editor. Reach for the chat panel when you want to explain what you are after; use AI Actions when one of the standard changes is what you need.

## What it can do

- Rewrite for clarity
- Shorten while keeping the point
- Change tone — warmer, more formal, more direct
- Fix grammar
- Translate
- Summarize
- Compose from a description
- Fill a briefing template with content you have already written

## How to use it

1. Open the [AI Assistant](/docs/ai/ai-assistant) and select **Writing Agent**.
2. Paste the text, or leave the **Document** context switch on to work on the brief of the document behind the panel.
3. Say what you want changed. Naming the reader helps: *"this goes to the client, make it warmer."*
4. Read the result before using it.

Chaining works. Rewrite first, then shorten, then adjust the tone.

## Rules and behaviour

- It answers in the language you wrote in unless you ask for another.
- It changes wording, not facts. Check any figure, date or name that matters before the text goes out.
- In the editor, an action replaces what is there. `Ctrl+Z` / `⌘+Z` puts it back.
