## What it helps with

The Workspace Assistant helps you improve workspaces and dashboards in Skills Workflow.

It is useful for tasks such as:

- adding or updating panels
- changing filters or widgets
- adjusting layout and panel size
- updating charts or grids
- making small, safe changes to workspace setup

## When to use it

Use this assistant when the request is about how a workspace or dashboard looks or behaves.

Good examples include:

- adding a new panel to a workspace
- changing a widget setting
- adjusting the layout of a dashboard
- updating a chart or filter
- refining one part of a workspace without changing everything

## Example requests

- `Add a kanban panel to this workspace`
- `Change this grid to show a filter row`
- `Update the chart configuration`
- `Move this panel and resize it`
- `Add a filter to this dashboard`

## What to have ready

- the workspace or dashboard name
- the panel or widget you want to change
- a short description of the result you want
- a screenshot, if it helps explain the layout
- any filter, chart, or panel details you already know

## When not to use it

- If you want to create or move documents, use the [Document Assistant](document-agent.md).
- If you want to change workflow stages or transitions, use the [Workflow Assistant](workflow-agent.md).
- If you only want help with text, use the [Writing Assistant](writing-agent.md).

## What to expect

The assistant works best with focused changes. If your request is broad, it may suggest starting with one panel, widget, or layout area at a time.
