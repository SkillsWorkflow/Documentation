# Using the platform

The order a project actually moves in, from the brief arriving to the hours being approved.

## Before you start

1. [Glossary](/docs/start-here/glossary) — the words the interface and the API use, including the
   cases where they disagree.
2. [Roles and profiles](/docs/administration/system-roles-profiles) — what you can see and do depends on
   your profile.
3. [Favorites](/docs/product/favorites) — getting back to the work you care about.

## Set the work up

4. [Client requests](/docs/product/briefing-and-requests/create-client-requests) — how work arrives from a
   client.
5. [Create a project](/docs/product/projects-and-jobs/create-projects) — the container everything
   else hangs from.
6. [Create jobs](/docs/product/projects-and-jobs/create-jobs) — breaking the project into the work
   that gets assigned.

## Plan it

7. [Using the Gantt](/docs/product/planning-and-scheduling/gantt) — dates,
   dependencies and the shape of the schedule.
8. [Resource scheduler](/docs/product/planning-and-scheduling/resourcing/resource-scheduler) — who
   is available, and for what.
9. [Assign an executor](/docs/product/people/teams/what-is-a-team) — putting a name against
   the work.
10. [Planned Time](/docs/product/planning-and-scheduling/resourcing/planned-hours) — how much time
    the work is expected to take.

## Do it and report it

11. [Filling in timesheets](/docs/product/time/timesheets/filling-time-sheets) — recording the
    hours.
12. [Timesheet timer](/docs/product/time/timesheets/timesheet-timer) — recording them as they
    happen instead.
13. [Annotations](/docs/product/files-and-collaboration/annotations) — reviewing files with feedback
    on the file itself.
14. [The feed](/docs/product/files-and-collaboration/using-feed) — where the conversation about a document
    lives.

## Follow it

15. [My tasks](/docs/product/projects-and-jobs/my-tasks) — your own queue.
16. [List view](/docs/product/projects-and-jobs/list-view) — filtering and shaping any list of
    documents.
17. [Approving timesheets](/docs/product/time/timesheets/approving-time-sheets) — for anyone who
    approves rather than submits.

## Where to go next

- [Administering a client](./administrator.md), if you also configure the platform.
- [Dashboards and reporting](/docs/product/dashboards-and-reporting) for the numbers behind all of
  the above.
