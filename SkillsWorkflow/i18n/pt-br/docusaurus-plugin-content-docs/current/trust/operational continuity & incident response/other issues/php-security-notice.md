Este artigo esclarece o impacto das vulnerabilidades no PHP CVE-2026-109618 e CVE-2026-109619 no Skills Workflow.

## Resumo do impacto

Em 21 de outubro de 2026, a equipe de segurança do PHP publicou alertas sobre duas vulnerabilidades críticas, CVE-2026-109618 e CVE-2026-109619, que podem permitir a execução remota de código não autorizado. O PHP é amplamente utilizado no desenvolvimento de aplicações web.

O Skills Workflow não é afetado por estas vulnerabilidades. Nem a aplicação nem os nossos sistemas internos utilizam PHP, portanto não há impacto na plataforma nem na infraestrutura que a suporta.

## Mitigação

Não é necessária nenhuma mitigação no Skills Workflow em relação a estas vulnerabilidades. Continuamos monitorando novas ameaças e mantendo medidas de segurança para proteger os nossos serviços e os dados dos clientes.

Para mais informações sobre estas vulnerabilidades, consulte o [site oficial do PHP](https://www.php.net).
