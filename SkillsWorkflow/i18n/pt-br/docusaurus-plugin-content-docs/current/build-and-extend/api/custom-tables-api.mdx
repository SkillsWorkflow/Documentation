### Descrição

A API de Tabelas Personalizadas permite criar, ler, atualizar e remover dados em tabelas definidas pelo usuário.

:::tip
Se você estiver trabalhando dentro de workspaces ou automações no Skills Workflow, prefira usar os **métodos do SDK** (`SW.Document.CustomTable.*`) documentados na [Referência do SDK](/docs/build-and-extend/sdk/document/customTable), em vez de chamar a API diretamente.
:::
