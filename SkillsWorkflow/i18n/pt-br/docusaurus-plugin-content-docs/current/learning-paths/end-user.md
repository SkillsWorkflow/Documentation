# Usar a plataforma

A ordem em que um projeto realmente avança, desde a chegada do brief até a aprovação das
horas.

## Antes de começar

1. [Glossário](/docs/start-here/glossary) — as palavras que a interface e a API usam,
   incluindo os casos em que discordam.
2. [Roles e Perfis](/docs/administration/system-roles-profiles) — o que você pode ver e fazer
   depende do seu perfil.
3. [Favoritos](/docs/product/favorites) — voltar ao trabalho que importa para você.

## Configure o trabalho

4. [Briefs de clientes](/docs/product/briefing-and-requests/create-client-requests) — como o
   trabalho chega vindo de um cliente.
5. [Criar um projeto](/docs/product/projects-and-jobs/create-projects) — o contêiner do qual
   tudo o resto depende.
6. [Criar atividades](/docs/product/projects-and-jobs/create-jobs) — dividir o projeto no
   trabalho que é atribuído.

## Planeje

7. [Usar o Gantt](/docs/product/planning-and-scheduling/gantt) — datas, dependências e o
   formato do cronograma.
8. [Alocação de recursos](/docs/product/planning-and-scheduling/resourcing/resource-scheduler)
   — quem está disponível, e para quê.
9. [Atribuir um executor](/docs/product/people/teams/what-is-a-team) — colocar um nome no
   trabalho.
10. [Tempo planejado](/docs/product/planning-and-scheduling/resourcing/planned-hours) — quanto
    tempo o trabalho deve levar.

## Faça e reporte

11. [Preencher time sheets](/docs/product/time/timesheets/filling-time-sheets) — registrar as
    horas.
12. [Cronômetro do time sheet](/docs/product/time/timesheets/timesheet-timer) — registrá-las à
    medida que acontecem, em vez disso.
13. [Anotações](/docs/product/files-and-collaboration/annotations) — revisar arquivos com
    feedback diretamente sobre o arquivo.
14. [O feed](/docs/product/files-and-collaboration/using-feed) — onde vive a conversa sobre um
    documento.

## Acompanhe

15. [Minhas tarefas](/docs/product/projects-and-jobs/my-tasks) — sua própria fila.
16. [Visão de lista](/docs/product/projects-and-jobs/list-view) — filtrar e moldar qualquer
    lista de documentos.
17. [Aprovar time sheets](/docs/product/time/timesheets/approving-time-sheets) — para quem
    aprova em vez de enviar.

## Para onde ir depois

- [Administrar um cliente](./administrator.md), se você também configura a plataforma.
- [Dashboards e relatórios](/docs/product/dashboards-and-reporting) para os números por trás
  de tudo isso.
