# Implementar a plataforma

Para quem configura e estende o Skills Workflow para um cliente.

Este percurso assume que você já entende o que os usuários do cliente fazem. Se não for o
caso, comece por [Usar a plataforma](./end-user.md) — as mesmas páginas que os usuários deles
leem.
