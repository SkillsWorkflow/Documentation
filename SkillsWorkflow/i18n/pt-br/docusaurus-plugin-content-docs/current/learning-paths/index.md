# Começar

Três trilhas pela documentação, cada uma na ordem em que o trabalho é realmente feito.

Cada passo leva à mesma página que o resto da documentação usa. Nada é escrito duas vezes, então nenhuma página pode estar atual em uma trilha e desatualizada em outra.

| Trilha | Para | Começa em |
| --- | --- | --- |
| [Usar a plataforma](/docs/learning-paths/end-user) | Quem faz o trabalho | Criar um projeto |
| [Administrar um cliente](/docs/learning-paths/administrator) | Administradores | Usuários e perfis |
| [Implementar a plataforma](/docs/learning-paths/consultant) | Consultores e desenvolvedores | Workspaces |

Você não precisa começar do início. Cada passo diz o que cobre, então você pode entrar em uma trilha onde estiver sua dúvida.
