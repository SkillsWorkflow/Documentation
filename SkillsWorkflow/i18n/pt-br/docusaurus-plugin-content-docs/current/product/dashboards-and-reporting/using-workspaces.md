# Usando workspaces

Um workspace é uma visão configurável construída sobre os dados próprios da plataforma. Os
workspaces são acessados a partir do menu **Workspaces**, e a maioria dos documentos no
Skills Workflow também pode ter seus próprios workspaces, ao lado de suas seções de Feed,
Info e Arquivos.

Os artigos desta área cobrem, cada um, um dos workspaces que vem com a plataforma.

## Disponibilidade

Quais workspaces uma pessoa vê depende dos workspaces configurados para o tenant e das
permissões dessa pessoa. Um documento só oferece workspaces se seu próprio tipo de documento
os habilitar.
