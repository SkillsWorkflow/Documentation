# Faturamento e Custos

A parte financeira da entrega. As autorizações de fatura pedem que um cliente seja faturado; as notas de crédito corrigem uma fatura para baixo. As ordens de compra comprometem uma compra a um fornecedor. As despesas e folhas de despesas registram o que a equipe gastou.
