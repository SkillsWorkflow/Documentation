A aba Orçamento pode ser usada só com o teclado. No macOS, use `⌘` no lugar de `Ctrl`.

## Na grade

| Teclas | O que fazem |
|---|---|
| `↑` `↓` `←` `→` `Tab` | Mover |
| Digitar, ou `Enter` / `F2` | Editar |
| `Enter` | Manter o valor e descer |
| `Shift`+`Enter` | Editar a descrição em uma caixa maior |
| `Esc` | Cancelar |
| `Delete` | Limpar a célula, ou as células selecionadas |
| `Shift`+`↑` `↓` `←` `→` | Selecionar várias células (ou `Shift`+clique) |
| `Ctrl`+`C` / `V` | Copiar, colar. Também blocos do Excel. Colar nas linhas vazias adiciona linhas |
| `Ctrl`+`D` | Preencher para baixo a partir da primeira linha selecionada, ou da linha acima |
| `Ctrl`+`Backspace` | Remover ou restaurar a linha, ou as linhas selecionadas |
| `Ctrl`+`S` | Salvar o orçamento |

## Linhas e entregáveis

| Teclas | O que fazem |
|---|---|
| `Alt`+`C` / `V` | Copiar as linhas selecionadas, ou colá-las como novas linhas. Também na WebApp |
| `Ctrl`+`Shift`+`↑` `↓` | Mover o entregável ou a linha para cima ou para baixo |
| `Alt`+`Enter` | Abrir as condições de compra de um serviço |
| `Alt`+`↓` / `↑` | Abrir ou fechar os detalhes |
| `Alt`+`Shift`+`↓` / `↑` | Expandir ou recolher tudo |
| `Alt`+`0` `1` `2` `3` | Mostrar todos os detalhes, ou só recursos, serviços ou despesas. De novo para ocultá-los |
| `Alt`+`B` | Ir para o plano de faturamento. De novo para ocultá-lo |
| `Alt`+`A` | Mostrar só os entregáveis aprovados, ou todos |

## Em uma lista

Uma lista abre enquanto você edita. Digite para filtrá-la. Nos grupos de cargo, qualquer parte da função, do departamento ou da empresa corresponde. Use `↑` e `↓` para escolher e `Enter` para selecionar e descer.

| Teclas | O que fazem |
|---|---|
| `Alt`+`↓` | Abrir ou fechar a lista |
| `Ctrl`+`Enter` | Na lista de grupos de cargo, marcar vários. Depois, `Enter` adiciona todos |
