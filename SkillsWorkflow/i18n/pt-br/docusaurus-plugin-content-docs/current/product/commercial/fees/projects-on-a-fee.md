:::note
Um Projeto pode ser associado a um Contrato, de forma que as horas vendidas nesse Contrato são descontadas à medida que as horas do Projeto são planejadas.
:::

1. Clique no ícone '+' para criar um novo Projeto.

![img-box-shadow](/img/university/contracts/university-contracts-projects-1.png)
<figcaption>Criação de um novo Projeto ou Orçamento a partir de um Contrato</figcaption>

2. Preencha o cabeçalho do projeto.

- Título - Adicione um nome para este projeto.
- Tipo - Selecione o tipo de projeto na lista suspensa.
- Data de Início e Término - Selecione o intervalo de datas para este projeto.
- Responsável pelo Projeto - Selecione o usuário responsável por este projeto.
- Contrato - Selecione o Contrato que deseja associar a este projeto.
- Entregável - Selecione o entregável que deseja associar a este projeto (entregáveis orçados).

Clique no ícone de confirmação para enviar.

![img-box-shadow](/img/university/contracts/university-contracts-projects-2.png)
<figcaption>Cabeçalho do projeto, com os campos Contrato e Entregável</figcaption>

3. Depois de criado o projeto, acesse a aba **Tempo Planejado** e preencha o formulário com as seguintes informações:

- Horas Contratadas - Clique no símbolo "Get Contracted Hours" para preencher esta coluna com as horas aprovadas no Contrato associado.
- Horas Planejadas - Ajuste as horas planejadas para este projeto, caso difiram das horas contratadas.
- Projeção - Clique no símbolo "Planned Hours Projection" para distribuir as horas planejadas ao longo do intervalo de datas do projeto.

![img-box-shadow](/img/university/contracts/university-contracts-projects-3.png)
<figcaption>Tempo Planejado, por grupo de tipologia</figcaption>

4. Analise as informações no Burn Workspace:

- Verifique o número de horas planejadas para cada grupo de tipologia.
- Verifique o número de horas preenchidas por todos os usuários incluídos nesse projeto.
- Verifique o número de horas disponíveis para cada grupo de tipologia.
- Verifique o % de utilização por grupo de tipologia.

![img-box-shadow](/img/university/contracts/university-contracts-projects-4.png)
<figcaption>Burn Workspace, por grupo de tipologia</figcaption>
