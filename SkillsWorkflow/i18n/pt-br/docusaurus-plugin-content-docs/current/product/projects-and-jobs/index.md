# Projetos e Jobs

Um projeto é o contêiner de um trabalho para um cliente; os jobs são as peças individuais de trabalho dentro dele. Esta área cobre a criação de ambos e as duas visualizações que a equipe usa para acompanhá-los: a visualização de lista e a lista de tarefas de cada pessoa.
