# Tempo

O tempo planejado diz o que deveria acontecer; as time sheets registram o que aconteceu. Esta área cobre o preenchimento de uma time sheet, o cronômetro, a transferência de horas entre projetos e o circuito de aprovação que uma time sheet enviada segue.
