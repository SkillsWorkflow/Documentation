# Briefing e Solicitações

Como o trabalho chega à agência. Um cliente abre uma solicitação e, a partir daí, ela se transforma nos projetos e jobs que a equipe entrega.

Para os templates que definem o que é pedido a quem solicita, consulte [Description Templates](/docs/administration/description-templates) em Administração.
