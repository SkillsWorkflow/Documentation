### Ler dados através de queries

Nas queries de **Maintenance → Queries**, use `CustomTable` como namespace.

```sql
SELECT Oid, Name, Price, IsActive
FROM [customtables].[ProductCatalog]
WHERE IsActive = 1
ORDER BY Name
```
