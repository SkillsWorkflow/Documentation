# Projetos e Jobs

Um projeto é o contentor de um trabalho para um cliente; os jobs são as peças individuais de trabalho dentro dele. Esta área cobre a criação de ambos e as duas vistas que a equipa usa para os acompanhar: a vista de lista e a lista de tarefas de cada pessoa.
