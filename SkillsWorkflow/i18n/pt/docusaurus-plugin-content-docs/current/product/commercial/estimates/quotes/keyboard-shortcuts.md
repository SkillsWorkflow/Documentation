O separador Orçamento pode ser usado só com o teclado. No macOS, use `⌘` em vez de `Ctrl`.

## Na grelha

| Teclas | O que fazem |
|---|---|
| `↑` `↓` `←` `→` `Tab` | Mover |
| Escrever, ou `Enter` / `F2` | Editar |
| `Enter` | Manter o valor e descer |
| `Shift`+`Enter` | Editar a descrição numa caixa maior |
| `Esc` | Cancelar |
| `Delete` | Limpar a célula, ou as células selecionadas |
| `Shift`+`↑` `↓` `←` `→` | Selecionar várias células (ou `Shift`+clique) |
| `Ctrl`+`C` / `V` | Copiar, colar. Também blocos do Excel. Colar nas linhas vazias adiciona linhas |
| `Ctrl`+`D` | Preencher para baixo a partir da primeira linha selecionada, ou da linha acima |
| `Ctrl`+`Backspace` | Remover ou repor a linha, ou as linhas selecionadas |
| `Ctrl`+`S` | Gravar a cotação |

## Linhas e entregáveis

| Teclas | O que fazem |
|---|---|
| `Alt`+`C` / `V` | Copiar as linhas selecionadas, ou colá-las como linhas novas. Também na WebApp |
| `Ctrl`+`Shift`+`↑` `↓` | Mover o entregável ou a linha para cima ou para baixo |
| `Alt`+`Enter` | Abrir as condições de compra de um serviço |
| `Alt`+`↓` / `↑` | Abrir ou fechar os detalhes |
| `Alt`+`Shift`+`↓` / `↑` | Expandir ou recolher tudo |
| `Alt`+`0` `1` `2` `3` | Mostrar todos os detalhes, ou só recursos, serviços ou despesas. De novo para os esconder |
| `Alt`+`B` | Ir para o plano de faturação. De novo para o esconder |
| `Alt`+`A` | Mostrar só os entregáveis aprovados, ou todos |

## Numa lista

Uma lista abre enquanto edita. Escreva para a filtrar. Nos grupos de tipologia, qualquer parte da função, do departamento ou da empresa corresponde. Use `↑` e `↓` para escolher, e `Enter` para selecionar e descer.

| Teclas | O que fazem |
|---|---|
| `Alt`+`↓` | Abrir ou fechar a lista |
| `Ctrl`+`Enter` | Na lista de grupos de tipologia, marcar vários. Depois, `Enter` adiciona-os todos |
