:::note
Um Projeto pode ser associado a um Contrato, de forma que as horas vendidas nesse Contrato são descontadas à medida que as horas do Projeto são planeadas.
:::

1. Clique no ícone '+' para criar um novo Projeto.

![img-box-shadow](/img/university/contracts/university-contracts-projects-1.png)
<figcaption>Criação de um novo Projeto ou Orçamento a partir de um Contrato</figcaption>

2. Preencha o cabeçalho do projeto.

- Título - Adicione um nome para este projeto.
- Tipo - Selecione o tipo de projeto na lista suspensa.
- Data de Início e Fim - Selecione o intervalo de datas para este projeto.
- Responsável do Projeto - Selecione o utilizador responsável por este projeto.
- Contrato - Selecione o Contrato que quer associar a este projeto.
- Entregável - Selecione o entregável que quer associar a este projeto (entregáveis orçamentados).

Clique no ícone de confirmação para submeter.

![img-box-shadow](/img/university/contracts/university-contracts-projects-2.png)
<figcaption>Cabeçalho do projeto, com os campos Contrato e Entregável</figcaption>

3. Depois de criado o projeto, aceda ao separador **Tempo Planeado** e preencha o formulário com a seguinte informação:

- Horas Contratadas - Clique no símbolo "Get Contracted Hours" para preencher esta coluna com as horas aprovadas no Contrato associado.
- Horas Planeadas - Ajuste as horas planeadas para este projeto, caso difiram das horas contratadas.
- Projeção - Clique no símbolo "Planned Hours Projection" para distribuir as horas planeadas ao longo do intervalo de datas do projeto.

![img-box-shadow](/img/university/contracts/university-contracts-projects-3.png)
<figcaption>Tempo Planeado, por grupo de tipologia</figcaption>

4. Analise a informação no Burn Workspace:

- Verifique o número de horas planeadas para cada grupo de tipologia.
- Verifique o número de horas preenchidas por todos os utilizadores incluídos nesse projeto.
- Verifique o número de horas disponíveis para cada grupo de tipologia.
- Verifique a % de utilização por grupo de tipologia.

![img-box-shadow](/img/university/contracts/university-contracts-projects-4.png)
<figcaption>Burn Workspace, por grupo de tipologia</figcaption>
