# Briefing e Pedidos

Como o trabalho chega à agência. Um cliente abre um pedido e, a partir daí, este transforma-se nos projetos e jobs que a equipa entrega.

Para os templates que definem o que é pedido a quem faz o pedido, consulte [Description Templates](/docs/administration/description-templates) em Administração.
