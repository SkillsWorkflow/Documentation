# Tempo

O tempo planeado diz o que deveria acontecer; as time sheets registam o que aconteceu. Esta área cobre o preenchimento de uma time sheet, o cronómetro, a transferência de horas entre projetos e o circuito de aprovação que uma time sheet submetida segue.
