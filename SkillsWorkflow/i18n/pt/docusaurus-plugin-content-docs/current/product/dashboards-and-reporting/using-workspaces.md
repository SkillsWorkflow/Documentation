# Usar workspaces

Um workspace é uma vista configurável construída sobre os dados próprios da plataforma. Os
workspaces são acedidos a partir do menu **Workspaces**, e a maioria dos documentos no Skills
Workflow também pode ter os seus próprios workspaces, ao lado das suas secções de Feed, Info e
Ficheiros.

Os artigos desta área cobrem, cada um, um dos workspaces que vem com a plataforma.

## Disponibilidade

Quais workspaces uma pessoa vê depende dos workspaces configurados para o tenant e das
permissões dessa pessoa. Um documento só oferece workspaces se o seu próprio tipo de documento
os ativar.
