# Planeamento

Depois de o trabalho existir, tem de ser planeado e ter pessoas atribuídas. O Gantt coloca os jobs de um projeto numa linha temporal e define as dependências entre eles. O planeador de recursos atribui pessoas a esse trabalho e mostra quem está sobrecarregado ou subutilizado. O tempo planeado regista quantas horas se espera que cada pessoa dedique.
