## Visão geral

Disponibiliza uma visão geral consolidada de vários portais de clientes, permitindo que os utilizadores monitorizem o estado de várias contas a partir de uma única vista.

:::info[O que perguntar]
Dá-me uma visão geral consolidada dos portais de [Client List]. Resume o estado dos projetos, pedidos pendentes, riscos e problemas críticos de cada cliente. Destaca as contas que precisam de atenção e indica links para os portais de cliente relevantes, quando disponíveis.
:::

:::tip[O que obtém]
Uma visão geral consolidada de vários portais de clientes, com o estado dos projetos, pedidos pendentes, riscos e problemas críticos de cada cliente, e links para os portais relevantes, quando disponíveis.
:::
