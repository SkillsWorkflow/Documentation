## Visão geral

Explora e compara cenários alternativos de estimate antes de criar um estimate, considerando diferentes âmbitos, recursos, rates, custos e orçamentos.

:::info[O que perguntar]
Ajuda-me a explorar diferentes cenários de estimate para [Client / Project] antes de criar o estimate.

O âmbito do projeto é: [Descreve o âmbito e os requisitos do projeto.]

Compara os seguintes cenários: [Descreve os âmbitos, recursos, horas, rates ou restrições orçamentais alternativos.]

Para cada cenário, resume os recursos necessários, as horas estimadas, os custos e o valor total. Destaca as principais diferenças, pressupostos e riscos potenciais para me ajudares a avaliar as alternativas antes de criar o estimate.
:::

:::tip[O que obtém]
Uma comparação de cenários alternativos de estimate, mostrando os recursos, as horas estimadas, os custos e os valores totais de cada opção, juntamente com as principais diferenças, pressupostos e riscos potenciais para apoiar a avaliação antes de criar o estimate.
:::
