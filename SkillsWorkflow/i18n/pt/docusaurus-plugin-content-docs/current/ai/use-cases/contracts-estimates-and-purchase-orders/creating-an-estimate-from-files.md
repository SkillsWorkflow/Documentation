## Visão geral

Extrai informação relevante de ficheiros carregados, como briefings, folhas de cálculo ou documentação de projeto, e utiliza-a para preparar um estimate.

## Prompt de exemplo

```
Cria um estimate para [Client / Project] utilizando os ficheiros anexados. Extrai o âmbito do projeto, os entregáveis, os recursos necessários, as horas estimadas, as rates, os custos e quaisquer condições relevantes. Organiza a informação num estimate com uma discriminação dos entregáveis, recursos, quantidades, rates e valores totais. Destaca qualquer informação em falta ou pressupostos que precisem de confirmação.
```

## Resultado esperado

Um estimate estruturado gerado a partir dos ficheiros anexados, contendo o âmbito do projeto extraído, os entregáveis, os recursos, as horas estimadas, as rates, os custos e os valores totais, com a informação em falta e os pressupostos assinalados para confirmação.
