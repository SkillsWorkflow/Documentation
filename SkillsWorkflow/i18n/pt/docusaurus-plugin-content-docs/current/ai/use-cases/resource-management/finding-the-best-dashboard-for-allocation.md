## Visão geral

Identifique o Dashboard mais adequado para monitorizar a alocação de recursos e disponibilize o acesso à vista relevante.

## Prompt de exemplo

```
Qual é o melhor Dashboard para monitorizar a alocação de recursos em [Equipa / Project / Período]? Identifica o Dashboard mais relevante e explica que informação de alocação ele fornece.
```

## Resultado esperado

O Dashboard mais relevante para monitorizar a alocação de recursos, incluindo o seu objetivo e a informação de alocação disponível através dele, com uma ligação para o Dashboard, quando disponível.
