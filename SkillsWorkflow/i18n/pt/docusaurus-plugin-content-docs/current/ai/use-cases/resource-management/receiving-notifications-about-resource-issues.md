## Visão geral

Identifique problemas relacionados com recursos, como overruns de recursos, atribuições inesperadas de recursos e desvios em relação à capacidade planeada. Forneça uma visão geral dos problemas que requerem atenção.

## Prompt de exemplo

```
Mostra-me os problemas relacionados com recursos que requerem atenção em [Projects / Equipa]. Identifica overruns de recursos, atribuições de recursos não planeadas ou inesperadas, e desvios em relação à capacidade planeada. Para cada problema, indica o Project afetado, o recurso, as datas relevantes e um resumo da situação.
```

## Resultado esperado

Uma lista consolidada dos problemas relacionados com recursos que requerem atenção, incluindo overruns de recursos, atribuições inesperadas e desvios em relação à capacidade planeada, com os Projects afetados, os recursos, as datas e os detalhes de cada problema.
