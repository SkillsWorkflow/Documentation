Cada um dos seguintes é um cenário real para o [Assistente de IA](/docs/ai/ai-assistant): o prompt a escrever no chat, e o resultado a verificar — não apenas uma capacidade genérica.

## Criar um Job Usando um Template de Briefing

**Visão geral**

Crie um novo job usando o [Agente de Documentos](/docs/ai/agents/document-agent) e gere automaticamente o respetivo brief com base no template de briefing configurado para o Job Type selecionado.

**Cenário**

Um gestor de projeto precisa de criar um novo job de campanha. Ao indicar os detalhes da campanha ao Agente de Documentos, o sistema cria o job e gera um brief seguindo a estrutura definida no template de briefing do Job Type.

**Prompt de exemplo**

```
Cria um novo job para o cliente Nike com os seguintes detalhes:

- Job Type: Digital Campaign
- Job Title: Nike Summer Campaign 2026
- Priority: High
- Description: Develop a digital campaign to promote Nike's summer collection.

Gera o brief do job usando o template de briefing configurado para este Job Type.
```

**Resultado esperado**

- É criado um novo job com a informação indicada.
- É selecionado o Job Type correto.
- O brief do job segue o template de briefing configurado para esse Job Type.
- O brief gerado inclui a informação relevante fornecida no prompt.

## Consulte o Burn Sem Abrir um Dashboard

**Visão geral**

Compare as horas contratadas com as horas realmente registadas, e o custo com a receita, diretamente a partir dos seus próprios relatórios — sem precisar de abrir um workspace primeiro.

**Cenário**

Um account manager quer verificar o burn de um retainer antes de uma chamada com o cliente, sem navegar até um workspace para encontrar o relatório certo.

**Prompt de exemplo**

```
Compara as horas contratadas vs. registadas no retainer da Northwind este mês.
```

**Resultado esperado**

- O assistente identifica o cliente ou projeto indicado no prompt.
- Responde a partir de um dos relatórios de extração de dados do seu tenant — os mesmos números por trás dos seus dashboards.
- O resultado é apresentado como um gráfico com uma tabela ao lado.

:::note
Responder a partir dos seus relatórios é uma capacidade que se concede a um agent, não algo ligado a um único agente pelo nome — veja [Ferramentas · Os seus dados](/docs/ai/ai-tools#your-data). Se o agente em que está disser que não consegue executar a query, pergunte a quem configurou a sua IA qual tem isto ativado.
:::

## Cubra Várias Contas, Não Só Uma

**Visão geral**

Peça um portal de cliente pelo nome e veja-o criado e publicado — depois peça o seguinte, na mesma conversa.

**Cenário**

Um account lead gere várias contas retainer e quer que cada uma tenha a sua própria página de status, sem as construir uma a uma através de um formulário.

**Prompt de exemplo**

```
Cria um portal de status para a Northwind. Depois cria o mesmo para a Acme, e para a Delta.
```

**Resultado esperado**

- É gerado um portal separado para cada cliente indicado.
- Cada portal lê os dados em tempo real desse cliente através das suas próprias permissões.
- Cada portal é publicado no seu próprio endereço.

Veja [Portais de Cliente](/docs/ai/ai-portals) para saber como um portal é publicado, e o que verificar antes de dar o link a um cliente.

## Veja o Que É Crítico em Todas as Suas Contas

**Visão geral**

Construa um dashboard que mostra overruns, riscos e aprovações pendentes em todos os clientes que gere, não só num de cada vez.

**Cenário**

Um studio lead quer uma única vista do que precisa de atenção em todas as contas, em vez de verificar o workspace de cada cliente um a um.

**Prompt de exemplo**

```
Cria-me um dashboard com a atividade crítica de todas as minhas contas — overruns, riscos e aprovações pendentes.
```

**Resultado esperado**

- O Agente de Workspaces propõe um dashboard que cobre todas as contas, não só um cliente.
- A proposta mostra overruns, riscos e aprovações pendentes.
- Nada é gravado até a proposta ser revista e aplicada.

Veja [Agente de Workspaces](/docs/ai/agents/workspace-agent) para saber como uma alteração a um workspace é construída e aplicada.

## Pergunte Pelos Projetos e Tarefas de um Cliente

**Visão geral**

Pesquise entre os jobs, deliverables e tarefas de um cliente e obtenha uma resposta direta, sem abrir cada um deles.

**Cenário**

Um project manager precisa de uma resposta rápida e exata sobre o que está em aberto na conta de um cliente, sem abrir cada job para verificar.

**Prompt de exemplo**

```
Que tarefas estão em aberto na conta da Northwind neste momento?
```

**Resultado esperado**

- O assistente pesquisa entre os jobs, deliverables e outros documentos desse cliente.
- Responde diretamente, indicando o que está em aberto.
- Clicar num resultado abre esse documento.

Veja [Agente de Documentos](/docs/ai/agents/document-agent) para a lista completa de tipos de documento que consegue pesquisar.
