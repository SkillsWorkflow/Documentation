Cada um dos seguintes é uma situação concreta, os passos e o prompt a escrever no [Assistente de IA](/docs/ai/ai-assistant), e o que esperar como resposta — não apenas uma capacidade genérica.

## Consulte o burn sem abrir um dashboard

**Situação:** Quer saber, agora mesmo, se um retainer ou projeto está a consumir mais horas do que as contratadas, sem precisar de abrir um workspace primeiro.

1. Abra o painel do [Assistente de IA](/docs/ai/ai-assistant).
2. Pergunte diretamente, indicando o cliente ou o projeto:

```
Compara as horas contratadas vs. registadas no retainer da Northwind este mês.
```

3. O assistente identifica o cliente ou projeto que indicou e responde a partir de um dos relatórios de extração de dados do seu tenant — os mesmos números por trás dos seus dashboards — apresentado como um gráfico com uma tabela ao lado.

:::note
Responder a partir dos seus relatórios é uma capacidade que se concede a um agent, não algo ligado a um único agente pelo nome — veja [Ferramentas · Os seus dados](/docs/ai/ai-tools#your-data). Se o agente em que está disser que não consegue executar a query, pergunte a quem configurou a sua IA qual tem isto ativado.
:::

## Cubra várias contas, não só uma

**Situação:** Gere várias contas de clientes e quer que cada uma tenha a sua própria página de status, sem as construir uma a uma através de um formulário.

1. Diga para que cliente é o portal e o que deve mostrar — status, burn, riscos, pedidos em aberto.
2. Assim que o primeiro estiver pronto, peça o portal do cliente seguinte na mesma conversa:

```
Cria um portal de status para a Northwind. Depois cria o mesmo para a Acme, e para a Delta.
```

3. Cada portal é gerado separadamente, a ler os dados em tempo real desse cliente através das suas próprias permissões. Veja [Portais de Cliente](/docs/ai/ai-portals) para saber como um portal é publicado, e o que verificar antes de dar o link a um cliente.

## Veja o que é crítico em todas as suas contas

**Situação:** Quer uma única vista que mostre o que precisa de atenção em todas as contas que gere, em vez de verificar o workspace de cada cliente um a um.

1. Abra o Assistente de IA, escolha o **Agente de Workspaces**, e abra (ou comece) o workspace onde quer isto.
2. Descreva o dashboard que quer:

```
Cria-me um dashboard com a atividade crítica de todas as minhas contas — overruns, riscos e aprovações pendentes.
```

3. Reveja a proposta antes de a aplicar — nada é gravado até o fazer. Veja [Agente de Workspaces](/docs/ai/agents/workspace-agent) para saber como uma alteração a um workspace é construída e aplicada.

## Pergunte pelos projetos e tarefas de um cliente

**Situação:** Precisa de uma resposta rápida e exata sobre o que está em aberto na conta de um cliente, sem abrir cada job para verificar.

1. Abra o Assistente de IA e escolha o **Agente de Documentos**.
2. Pergunte, indicando o cliente:

```
Que tarefas estão em aberto na conta da Northwind neste momento?
```

3. O assistente pesquisa entre os jobs, deliverables e outros documentos desse cliente e responde diretamente; clique num resultado para o abrir. Veja [Agente de Documentos](/docs/ai/agents/document-agent) para a lista completa de tipos de documento que consegue pesquisar.
