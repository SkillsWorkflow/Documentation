## Em que ajuda

O Assistente de Escrita ajuda a melhorar texto.

É útil para tarefas como:

- reescrever uma mensagem
- melhorar a gramática
- tornar o texto mais curto
- tornar o texto mais claro
- mudar o tom
- polir conteúdo para uso profissional

## Quando usar

Use este assistente quando quer melhorar wording e não executar uma ação na plataforma.

Bons exemplos incluem:

- melhorar um email antes de o enviar
- transformar notas num resumo claro
- tornar instruções mais curtas e fáceis de ler
- mudar o tom de uma mensagem
- rever gramática e estilo

## Exemplos de pedidos

- `Rewrite this email in a friendlier tone`
- `Make this paragraph more concise`
- `Proofread this message`
- `Turn these notes into a polished summary`
- `Make this sound more professional`

## O que convém ter preparado

- o texto que quer melhorar
- o tom que quer, se já o souber
- o público a quem se destina, se isso importar
- qualquer preferência de comprimento ou estilo

## Quando não usar

- Se quer criar ou atualizar um documento na plataforma, use o [Assistente de Documentos](document-agent.mdx).
- Se quer alterar a configuração de workflows, use o [Assistente de Workflows](workflow-agent.mdx).
- Se quer editar um workspace ou dashboard, use o [Assistente de Workspaces](workspace-agent.mdx).

## O que esperar

Este assistente foi pensado para ser simples. Na maior parte dos casos, basta colar o texto, dizer o que quer melhorar e receber um resultado pronto a usar.
