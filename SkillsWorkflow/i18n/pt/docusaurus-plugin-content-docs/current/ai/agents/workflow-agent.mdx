## Em que ajuda

O Assistente de Workflows ajuda a rever e alterar a forma como os documentos passam por um workflow.

É útil para tarefas como:

- rever um workflow existente
- adicionar ou alterar stages
- criar transições entre stages
- ajustar fluxos de aprovação
- definir quem pode usar uma transição
- alterar motivos ou ações ligados a uma transição

## Quando usar

Use este assistente quando o pedido é sobre a configuração do workflow em si.

Bons exemplos incluem:

- verificar como um tipo de documento passa de draft para approval
- adicionar um novo stage
- criar uma nova transição
- limitar uma transição a uma role ou equipa
- rever o workflow atual antes de fazer alterações

## Exemplos de pedidos

- `Show me the workflow for Deliverables`
- `Create a new stage called Under Validation`
- `Add a transition from Draft to Approved`
- `Restrict this transition to managers`
- `Show me which actions are configured on this transition`

## O que convém ter preparado

- o nome do workflow ou do tipo de documento
- os nomes dos stages que quer rever ou alterar
- a mudança que quer fazer
- a role ou equipa envolvida, se o acesso for importante
- qualquer regra de aprovação ou rejeição que queira adicionar

## Quando não usar

- Se quer criar ou atualizar um documento, use o [Assistente de Documentos](document-agent.mdx).
- Se quer ajuda a reescrever texto, use o [Assistente de Escrita](writing-agent.mdx).
- Se quer alterar um workspace ou dashboard, use o [Assistente de Workspaces](workspace-agent.mdx).

## O que esperar

O assistente normalmente começa por rever o workflow atual e depois guia a alteração. Em mudanças maiores, pode avançar passo a passo para manter tudo claro e correto.
