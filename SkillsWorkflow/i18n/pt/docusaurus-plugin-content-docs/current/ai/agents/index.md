## Escolha o assistente certo

O Skills Workflow inclui assistentes de IA focados em tarefas específicas. Cada assistente foi pensado para um tipo de pedido, para que seja mais fácil obter o resultado certo sem precisar de usar pedidos demasiado técnicos.

## Assistentes disponíveis

| Assistente | Melhor para | Exemplo de pedido |
| --- | --- | --- |
| [Assistente de Documentos](document-agent.md) | Criar, atualizar, procurar, duplicar ou mover documentos como jobs e deliverables | `Create a job from this client request` |
| [Assistente de Workflows](workflow-agent.md) | Rever ou alterar stages, transições e fluxos de aprovação | `Show me the workflow for Deliverables` |
| [Assistente de Escrita](writing-agent.md) | Reescrever, melhorar, encurtar ou clarificar texto | `Rewrite this in a more professional tone` |
| [Assistente de Workspaces](workspace-agent.md) | Ajustar workspaces, dashboards, painéis, filtros e widgets | `Add a kanban panel to this workspace` |

## Que assistente devo usar?

- Use o [Assistente de Documentos](document-agent.md) quando quer fazer algo com um documento real na plataforma.
- Use o [Assistente de Workflows](workflow-agent.md) quando quer alterar a forma como os documentos passam de um stage para outro.
- Use o [Assistente de Escrita](writing-agent.md) quando só precisa de ajuda com texto.
- Use o [Assistente de Workspaces](workspace-agent.md) quando quer alterar um workspace ou dashboard.

## Dicas para melhores resultados

- Diga em linguagem simples o que quer alcançar.
- Partilhe nomes como o documento, projeto, workflow ou workspace, se os souber.
- Junte screenshots ou ficheiros quando ajudarem a explicar o pedido.
- Se quer um tom ou layout específico, diga qual.
