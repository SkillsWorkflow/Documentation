O Agente de Escrita trabalha sobre texto. Dê-lhe algo que escreveu e diga o que está mal — demasiado longo, demasiado seco, no idioma errado, pouco claro — e ele devolve o texto alterado.

É também o agente por trás das [Ações de IA](/docs/ai/ai-actions), o botão na barra de ferramentas de todos os editores de texto enriquecido. Use o painel de chat quando quiser explicar o que pretende; use as Ações de IA quando uma das alterações-padrão é o que precisa.

## O que consegue fazer

- Reescrever para ganhar clareza
- Encurtar sem perder o essencial
- Mudar o tom — mais caloroso, mais formal, mais direto
- Corrigir gramática
- Traduzir
- Resumir
- Compor a partir de uma descrição
- Preencher um template de briefing com conteúdo que já escreveu

## Como usar

1. Abra o [Assistente de IA](/docs/ai/ai-assistant) e selecione **Agente de Escrita**.
2. Cole o texto, ou deixe ligado o interruptor de contexto **Document** para trabalhar sobre o brief do documento por trás do painel.
3. Diga o que quer mudado. Indicar o destinatário ajuda: *"isto vai para o cliente, torna-o mais caloroso."*
4. Leia o resultado antes de o usar.

Encadear funciona. Primeiro reescrever, depois encurtar, depois ajustar o tom.

## Regras e comportamento

- Responde no idioma em que escreveu, a não ser que peça outro.
- Muda as palavras, não os factos. Verifique qualquer número, data ou nome que importe antes de o texto sair.
- No editor, uma ação substitui o que lá está. `Ctrl+Z` / `⌘+Z` repõe.
