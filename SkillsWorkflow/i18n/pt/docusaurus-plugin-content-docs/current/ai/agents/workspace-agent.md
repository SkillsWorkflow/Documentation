## Em que ajuda

O Assistente de Workspaces ajuda a melhorar workspaces e dashboards no Skills Workflow.

É útil para tarefas como:

- adicionar ou atualizar painéis
- alterar filtros ou widgets
- ajustar layout e tamanho dos painéis
- atualizar gráficos ou grelhas
- fazer pequenas alterações seguras à configuração do workspace

## Quando usar

Use este assistente quando o pedido é sobre a forma como um workspace ou dashboard aparece ou se comporta.

Bons exemplos incluem:

- adicionar um novo painel a um workspace
- alterar a configuração de um widget
- ajustar o layout de um dashboard
- atualizar um gráfico ou filtro
- melhorar uma parte específica do workspace sem mudar tudo

## Exemplos de pedidos

- `Add a kanban panel to this workspace`
- `Change this grid to show a filter row`
- `Update the chart configuration`
- `Move this panel and resize it`
- `Add a filter to this dashboard`

## O que convém ter preparado

- o nome do workspace ou dashboard
- o painel ou widget que quer alterar
- uma descrição curta do resultado pretendido
- uma screenshot, se ajudar a explicar o layout
- quaisquer detalhes sobre filtros, gráficos ou painéis que já saiba

## Quando não usar

- Se quer criar ou mover documentos, use o [Assistente de Documentos](document-agent.md).
- Se quer alterar stages ou transições de workflow, use o [Assistente de Workflows](workflow-agent.md).
- Se só quer ajuda com texto, use o [Assistente de Escrita](writing-agent.md).

## O que esperar

O assistente funciona melhor com alterações focadas. Se o pedido for muito amplo, pode sugerir começar por um painel, widget ou área do layout de cada vez.
