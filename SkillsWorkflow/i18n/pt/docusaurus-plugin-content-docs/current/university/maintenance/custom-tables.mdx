## Visão geral

As Tabelas Personalizadas permitem estender o modelo de dados do Skills Workflow com tabelas, colunas e tipos de dados próprios.

---

## Navegar para Tabelas Personalizadas

1. Vá a **Maintenance**
2. Escolha o módulo **Custom Tables**

<figure>

![img-box-shadow](/img/maintenance/custom_tables_list.png)

<figcaption>Lista de tabelas personalizadas</figcaption>
</figure>

---

## Criar uma tabela personalizada

1. Clique em **+**
2. Defina o nome da tabela
3. Configure a coluna chave, normalmente `Oid`
4. Adicione as colunas e respetivos tipos de dados

<figure>

![img-box-shadow](/img/maintenance/custom_tables_create.png)

<figcaption>Criação de uma nova tabela personalizada</figcaption>
</figure>

---

## Permissões

Cada tabela tem:

- **Read Role** para leitura
- **Save Role** para inserção, atualização e remoção

<figure>

![img-box-shadow](/img/maintenance/custom_tables_permissions.png)

<figcaption>Configuração de permissões</figcaption>
</figure>

---

## Ler dados por query

Use o namespace `CustomTable` nas queries e consulte o esquema `[customtables]`.

```sql
SELECT Oid, Name, Price, IsActive
FROM [customtables].[ProductCatalog]
WHERE IsActive = 1
ORDER BY Name
```
