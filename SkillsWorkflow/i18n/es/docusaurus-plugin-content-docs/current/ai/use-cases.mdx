Cada uno de los siguientes es una situación concreta, los pasos y el prompt que escribir en el [Asistente de IA](/docs/ai/ai-assistant), y qué esperar como respuesta — no solo una capacidad genérica.

## Consulta el burn sin abrir un dashboard

**Situación:** Quieres saber, ahora mismo, si un retainer o proyecto está consumiendo más horas de las contratadas, sin necesidad de abrir antes un workspace.

1. Abre el panel del [Asistente de IA](/docs/ai/ai-assistant).
2. Pregúntale directamente, indicando el cliente o el proyecto:

```
Compara las horas contratadas vs. registradas en el retainer de Northwind este mes.
```

3. El asistente identifica el cliente o proyecto que indicaste y responde a partir de uno de los informes de extracción de datos de tu tenant — las mismas cifras detrás de tus dashboards — mostrado como un gráfico con una tabla al lado.

:::note
Responder a partir de tus informes es una capacidad que se concede a un agent, no algo ligado a un único agente por su nombre — consulta [Herramientas · Tus datos](/docs/ai/ai-tools#your-data). Si el agente en el que estás dice que no puede ejecutar la query, pregunta a quien configuró tu IA cuál la tiene activada.
:::

## Cubre varias cuentas, no solo una

**Situación:** Gestionas varias cuentas de clientes y quieres que cada una tenga su propia página de estado, sin construirlas una a una a través de un formulario.

1. Di para qué cliente es el portal y qué debe mostrar — estado, burn, riesgos, peticiones abiertas.
2. En cuanto el primero esté listo, pide el portal del siguiente cliente en la misma conversación:

```
Crea un portal de estado para Northwind. Luego crea el mismo para Acme, y para Delta.
```

3. Cada portal se genera por separado, leyendo los datos en tiempo real de ese cliente a través de sus propios permisos. Consulta [Portales de Cliente](/docs/ai/ai-portals) para saber cómo se publica un portal, y qué comprobar antes de darle el enlace a un cliente.

## Ve qué es crítico en todas tus cuentas

**Situación:** Quieres una única vista que muestre lo que necesita atención en todas las cuentas que gestionas, en vez de revisar el workspace de cada cliente uno a uno.

1. Abre el Asistente de IA, elige el **Agente de Workspaces**, y abre (o crea) el workspace donde quieres esto.
2. Describe el dashboard que quieres:

```
Constrúyeme un dashboard con la actividad crítica de todas mis cuentas — overruns, riesgos y aprobaciones pendientes.
```

3. Revisa la propuesta antes de aplicarla — nada se guarda hasta que lo hagas. Consulta [Agente de Workspaces](/docs/ai/agents/workspace-agent) para saber cómo se construye y aplica un cambio de workspace.

## Pregunta por los proyectos y tareas de un cliente

**Situación:** Necesitas una respuesta rápida y exacta sobre qué está abierto en la cuenta de un cliente, sin abrir cada job para comprobarlo.

1. Abre el Asistente de IA y elige el **Agente de Documentos**.
2. Pregunta, indicando el cliente:

```
¿Qué tareas están abiertas en la cuenta de Northwind ahora mismo?
```

3. El asistente busca entre los jobs, deliverables y otros documentos de ese cliente y responde directamente; haz clic en un resultado para abrirlo. Consulta [Agente de Documentos](/docs/ai/agents/document-agent) para la lista completa de tipos de documento que puede buscar.
