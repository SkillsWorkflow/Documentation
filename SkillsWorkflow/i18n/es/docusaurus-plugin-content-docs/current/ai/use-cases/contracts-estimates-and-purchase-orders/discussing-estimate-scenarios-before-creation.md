## Visión general

Explora y compara escenarios alternativos de estimate antes de crear un estimate, considerando diferentes alcances, recursos, rates, costos y presupuestos.

:::info[Qué preguntar]
Ayúdame a explorar diferentes escenarios de estimate para [Client / Project] antes de crear el estimate.

El alcance del proyecto es: [Describe el alcance y los requisitos del proyecto.]

Compara los siguientes escenarios: [Describe los alcances, recursos, horas, rates o restricciones presupuestarias alternativos.]

Para cada escenario, resume los recursos necesarios, las horas estimadas, los costos y el monto total. Destaca las principales diferencias, suposiciones y riesgos potenciales para ayudarme a evaluar las alternativas antes de crear el estimate.
:::

:::tip[Qué obtienes]
Una comparación de escenarios alternativos de estimate, que muestra los recursos, las horas estimadas, los costos y los montos totales de cada opción, junto con las principales diferencias, suposiciones y riesgos potenciales para apoyar la evaluación antes de crear el estimate.
:::
