## En qué ayuda

El Asistente de Workflows te ayuda a revisar y cambiar cómo pasan los documentos por un workflow.

Es útil para tareas como:

- revisar un workflow existente
- añadir o cambiar stages
- crear transiciones entre stages
- ajustar flujos de aprobación
- definir quién puede usar una transición
- cambiar motivos o acciones ligados a una transición

## Cuándo usarlo

Usa este asistente cuando la solicitud trate sobre la configuración del workflow.

Buenos ejemplos son:

- revisar cómo un tipo de documento pasa de draft a approval
- añadir un nuevo stage
- crear una nueva transición
- limitar una transición a una role o equipo
- revisar el workflow actual antes de hacer cambios

## Ejemplos de solicitudes

- `Show me the workflow for Deliverables`
- `Create a new stage called Under Validation`
- `Add a transition from Draft to Approved`
- `Restrict this transition to managers`
- `Show me which actions are configured on this transition`

## Qué conviene tener preparado

- el nombre del workflow o del tipo de documento
- los nombres de los stages que quieres revisar o cambiar
- el cambio que quieres hacer
- la role o el equipo implicado, si el acceso es importante
- cualquier regla de aprobación o rechazo que quieras añadir

## Cuándo no usarlo

- Si quieres crear o actualizar un documento, usa el [Asistente de Documentos](document-agent.md).
- Si quieres ayuda para reescribir texto, usa el [Asistente de Escritura](writing-agent.md).
- Si quieres cambiar un workspace o dashboard, usa el [Asistente de Workspaces](workspace-agent.md).

## Qué esperar

El asistente suele empezar revisando el workflow actual y después guía el cambio. En cambios más grandes, puede avanzar paso a paso para mantener todo claro y correcto.
