## En qué ayuda

El Asistente de Escritura te ayuda a mejorar texto.

Es útil para tareas como:

- reescribir un mensaje
- mejorar la gramática
- hacer el texto más corto
- hacer el texto más claro
- cambiar el tono
- pulir contenido para uso profesional

## Cuándo usarlo

Usa este asistente cuando quieras mejorar el wording y no ejecutar una acción en la plataforma.

Buenos ejemplos son:

- mejorar un correo antes de enviarlo
- convertir notas en un resumen claro
- hacer instrucciones más cortas y fáciles de leer
- cambiar el tono de un mensaje
- revisar gramática y estilo

## Ejemplos de solicitudes

- `Rewrite this email in a friendlier tone`
- `Make this paragraph more concise`
- `Proofread this message`
- `Turn these notes into a polished summary`
- `Make this sound more professional`

## Qué conviene tener preparado

- el texto que quieres mejorar
- el tono que quieres, si ya lo tienes claro
- el público al que va dirigido, si importa
- cualquier preferencia de longitud o estilo

## Cuándo no usarlo

- Si quieres crear o actualizar un documento en la plataforma, usa el [Asistente de Documentos](document-agent.mdx).
- Si quieres cambiar la configuración de workflows, usa el [Asistente de Workflows](workflow-agent.mdx).
- Si quieres editar un workspace o dashboard, usa el [Asistente de Workspaces](workspace-agent.mdx).

## Qué esperar

Este asistente está pensado para ser simple. En la mayoría de los casos, basta con pegar el texto, decir qué quieres mejorar y recibir un resultado listo para usar.
