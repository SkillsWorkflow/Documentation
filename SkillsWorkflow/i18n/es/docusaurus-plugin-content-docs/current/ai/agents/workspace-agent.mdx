## En qué ayuda

El Asistente de Workspaces te ayuda a mejorar workspaces y dashboards en Skills Workflow.

Es útil para tareas como:

- añadir o actualizar paneles
- cambiar filtros o widgets
- ajustar el layout y el tamaño de los paneles
- actualizar gráficos o rejillas
- hacer cambios pequeños y seguros en la configuración del workspace

## Cuándo usarlo

Usa este asistente cuando la solicitud trate sobre cómo se ve o cómo funciona un workspace o dashboard.

Buenos ejemplos son:

- añadir un panel nuevo a un workspace
- cambiar la configuración de un widget
- ajustar el layout de un dashboard
- actualizar un gráfico o filtro
- mejorar una parte concreta del workspace sin cambiarlo todo

## Ejemplos de solicitudes

- `Add a kanban panel to this workspace`
- `Change this grid to show a filter row`
- `Update the chart configuration`
- `Move this panel and resize it`
- `Add a filter to this dashboard`

## Qué conviene tener preparado

- el nombre del workspace o dashboard
- el panel o widget que quieres cambiar
- una descripción breve del resultado que quieres
- una captura, si ayuda a explicar el layout
- cualquier detalle sobre filtros, gráficos o paneles que ya conozcas

## Cuándo no usarlo

- Si quieres crear o mover documentos, usa el [Asistente de Documentos](document-agent.mdx).
- Si quieres cambiar stages o transiciones de workflow, usa el [Asistente de Workflows](workflow-agent.mdx).
- Si solo quieres ayuda con texto, usa el [Asistente de Escritura](writing-agent.mdx).

## Qué esperar

El asistente funciona mejor con cambios concretos. Si la solicitud es muy amplia, puede sugerir empezar por un panel, widget o zona del layout cada vez.
