## Elige el asistente adecuado

Skills Workflow incluye asistentes de IA centrados en tareas concretas. Cada asistente está pensado para un tipo de solicitud, de modo que sea más fácil obtener el resultado correcto sin usar instrucciones demasiado técnicas.

## Asistentes disponibles

| Asistente | Mejor para | Ejemplo de solicitud |
| --- | --- | --- |
| [Asistente de Documentos](document-agent.mdx) | Crear, actualizar, buscar, duplicar o mover documentos como jobs y deliverables | `Create a job from this client request` |
| [Asistente de Workflows](workflow-agent.mdx) | Revisar o cambiar stages, transiciones y flujos de aprobación | `Show me the workflow for Deliverables` |
| [Asistente de Escritura](writing-agent.mdx) | Reescribir, mejorar, acortar o aclarar texto | `Rewrite this in a more professional tone` |
| [Asistente de Workspaces](workspace-agent.mdx) | Ajustar workspaces, dashboards, paneles, filtros y widgets | `Add a kanban panel to this workspace` |

## ¿Qué asistente debo usar?

- Usa el [Asistente de Documentos](document-agent.mdx) cuando quieras hacer algo con un documento real en la plataforma.
- Usa el [Asistente de Workflows](workflow-agent.mdx) cuando quieras cambiar cómo pasan los documentos de un stage a otro.
- Usa el [Asistente de Escritura](writing-agent.mdx) cuando solo necesites ayuda con texto.
- Usa el [Asistente de Workspaces](workspace-agent.mdx) cuando quieras cambiar un workspace o dashboard.

## Consejos para obtener mejores resultados

- Explica con lenguaje sencillo lo que quieres conseguir.
- Comparte nombres como el documento, proyecto, workflow o workspace, si los conoces.
- Añade capturas o archivos cuando ayuden a explicar la solicitud.
- Si quieres un tono o un layout concreto, indícalo.

## Próximos pasos

- Lee [Asistente de Documentos](document-agent.mdx) si trabajas principalmente con jobs, deliverables y otros documentos.
- Lee [Asistente de Workflows](workflow-agent.mdx) si gestionas la configuración de workflows y aprobaciones.
- Lee [Asistente de Escritura](writing-agent.mdx) si quieres ayuda para escribir o reescribir texto.
- Lee [Asistente de Workspaces](workspace-agent.mdx) si quieres mejorar dashboards y layouts de workspace.
