### Descripción

La API de Tablas Personalizadas permite crear, leer, actualizar y eliminar datos en tablas definidas por el usuario.

:::tip
Si trabaja dentro de espacios de trabajo o automatizaciones de Skills Workflow, prefiera usar los **métodos del SDK** (`SW.Document.CustomTable.*`) documentados en la [Referencia del SDK](/docs/sdk/document/customTable) en lugar de llamar a la API directamente.
:::
