# Empezar

Tres rutas por la documentación, cada una en el orden en que el trabajo se hace realmente.

Cada paso enlaza a la misma página que usa el resto de la documentación. Nada se escribe dos veces, así que ninguna página puede estar actualizada en una ruta y obsoleta en otra.

| Ruta | Para | Empieza por |
| --- | --- | --- |
| [Usar la plataforma](/docs/learning-paths/end-user) | Cualquiera que haga el trabajo | Crear un proyecto |
| [Administrar un cliente](/docs/learning-paths/administrator) | Administradores | Usuarios y perfiles |
| [Implementar la plataforma](/docs/learning-paths/consultant) | Consultores y desarrolladores | Workspaces |

No hace falta empezar por el principio. Cada paso indica qué cubre, así que puede unirse a una ruta donde esté su pregunta.
