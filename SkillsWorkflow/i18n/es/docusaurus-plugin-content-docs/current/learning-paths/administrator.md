# Administrar un cliente

El orden en el que normalmente se configura un cliente. Cada paso es configuración de la que
dependen los pasos siguientes, así que merece la pena seguir la secuencia la primera vez.

## Entender el modelo primero

1. [Glosario](/docs/start-here/glossary) — los términos que usan las pantallas de configuración.
2. [Roles y Perfiles](/docs/administration/system-roles-profiles) — cómo se concede el acceso, y
   el vocabulario que asume el resto de este recorrido.

## Personas

3. [Crear un usuario](/docs/administration/users/create-user)
4. [Editar un perfil](/docs/administration/users/edit-profile) — qué controla un perfil.

6. [Equipos y grupos](/docs/product/people/teams/what-is-a-team) — cómo se distribuye el
   trabajo una vez que existen los usuarios.

## Calendarios

7. [Días festivos](/docs/administration/calendars/create-holidays) — afectan a la

9. [Tipos de ausencia](/docs/administration/calendars/create-assign-type)
