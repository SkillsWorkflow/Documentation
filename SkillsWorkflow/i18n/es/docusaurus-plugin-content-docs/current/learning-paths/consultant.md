# Implementar la plataforma

Para quienes configuran y extienden Skills Workflow para un cliente.

Este recorrido asume que ya entiendes qué hacen los usuarios del cliente. Si no es así, empieza
por [Usar la plataforma](./end-user.md) — las mismas páginas que leen sus usuarios.

## Sitúate primero

   usan nombres distintos para lo mismo.
2. [Administrar un cliente](./administrator.md) — la configuración sobre la que se apoya todo
   lo demás.
