Este artículo explica el impacto de las vulnerabilidades de PHP CVE-2026-109618 y CVE-2026-109619 en Skills Workflow.

## Resumen del impacto

El 21 de octubre de 2026, el equipo de seguridad de PHP publicó alertas sobre dos vulnerabilidades críticas, CVE-2026-109618 y CVE-2026-109619, que pueden permitir la ejecución remota de código no autorizado. PHP se utiliza ampliamente en el desarrollo de aplicaciones web.

Skills Workflow no se ve afectado por estas vulnerabilidades. Ni la aplicación ni nuestros sistemas internos utilizan PHP, por lo que no hay impacto en la plataforma ni en la infraestructura que la sustenta.

## Mitigación

No se requiere ninguna mitigación en Skills Workflow en relación con estas vulnerabilidades. Seguimos supervisando nuevas amenazas y manteniendo medidas de seguridad para proteger nuestros servicios y los datos de los clientes.

Para obtener más información sobre estas vulnerabilidades, consulte el [sitio web oficial de PHP](https://www.php.net).
