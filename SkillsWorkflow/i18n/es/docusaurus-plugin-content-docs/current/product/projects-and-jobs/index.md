# Proyectos y Jobs

Un proyecto es el contenedor de un trabajo para un cliente; los jobs son las piezas individuales de trabajo dentro de él. Esta área cubre la creación de ambos y las dos vistas que el equipo usa para seguirlos: la vista de lista y la lista de tareas de cada persona.
