:::note
Un Proyecto puede asociarse a un Fee, de forma que las horas vendidas bajo ese Fee se descuentan a medida que se planifican las horas del Proyecto.
:::

1. Haga clic en el icono '+' para crear un nuevo Proyecto.

![img-box-shadow](/img/university/contracts/university-contracts-projects-1.png)
<figcaption>Creación de un nuevo Proyecto o Estimación desde un Fee</figcaption>

2. Complete el encabezado del proyecto.

- Título - Añada un nombre para este proyecto.
- Tipo - Seleccione el tipo de proyecto de la lista desplegable.
- Fechas de inicio y fin - Seleccione el rango de fechas para este proyecto.
- Propietario del proyecto - Seleccione el usuario responsable de este proyecto.
- Fee - Seleccione el Fee que quiere asociar a este proyecto.
- Entregable - Seleccione el entregable que quiere asociar a este proyecto (entregables estimados).

Haga clic en el icono de check para enviar.

![img-box-shadow](/img/university/contracts/university-contracts-projects-2.png)
<figcaption>Encabezado del proyecto, con sus campos Fee y Entregable</figcaption>

3. Después de crear el proyecto, vaya a la pestaña **Tiempo Planificado** y complete el formulario con la siguiente información:

- Horas Contratadas - Haga clic en el símbolo "Get Contracted Hours" para rellenar esta columna con las horas aprobadas en el Fee asociado.
- Horas Planificadas - Ajuste las horas planificadas para este proyecto, si difieren de las horas contratadas.
- Proyección - Haga clic en el símbolo "Planned Hours Projection" para distribuir las horas planificadas a lo largo del rango de fechas del proyecto.

![img-box-shadow](/img/university/contracts/university-contracts-projects-3.png)
<figcaption>Tiempo Planificado, por grupo de tipología</figcaption>

4. Analice la información del Burn Workspace:

- Compruebe el número de horas planificadas para cada grupo de tipología.
- Compruebe el número de horas rellenadas por todos los usuarios incluidos en ese proyecto.
- Compruebe el número de horas disponibles para cada grupo de tipología.
- Compruebe el % de utilización por grupo de tipología.

![img-box-shadow](/img/university/contracts/university-contracts-projects-4.png)
<figcaption>Burn Workspace, por grupo de tipología</figcaption>
