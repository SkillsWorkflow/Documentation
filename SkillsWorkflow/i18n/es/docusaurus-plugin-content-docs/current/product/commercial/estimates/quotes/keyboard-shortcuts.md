La pestaña Presupuesto se puede usar solo con el teclado. En macOS, use `⌘` en lugar de `Ctrl`.

## En la cuadrícula

| Teclas | Qué hacen |
|---|---|
| `↑` `↓` `←` `→` `Tab` | Moverse |
| Escribir, o `Enter` / `F2` | Editar |
| `Enter` | Mantener el valor y bajar |
| `Shift`+`Enter` | Editar la descripción en un cuadro más grande |
| `Esc` | Cancelar |
| `Delete` | Vaciar la celda, o las celdas seleccionadas |
| `Shift`+`↑` `↓` `←` `→` | Seleccionar varias celdas (o `Shift`+clic) |
| `Ctrl`+`C` / `V` | Copiar, pegar. También bloques de Excel. Pegar en filas vacías añade líneas |
| `Ctrl`+`D` | Rellenar hacia abajo desde la primera fila seleccionada, o desde la fila de arriba |
| `Ctrl`+`Backspace` | Quitar o restaurar la fila, o las filas seleccionadas |
| `Ctrl`+`S` | Guardar la cotización |

## Filas y entregables

| Teclas | Qué hacen |
|---|---|
| `Alt`+`C` / `V` | Copiar las filas seleccionadas, o pegarlas como filas nuevas. También en la WebApp |
| `Ctrl`+`Shift`+`↑` `↓` | Mover el entregable o la línea arriba o abajo |
| `Alt`+`Enter` | Abrir las condiciones de compra de un servicio |
| `Alt`+`↓` / `↑` | Abrir o cerrar los detalles |
| `Alt`+`Shift`+`↓` / `↑` | Expandir o contraer todo |
| `Alt`+`0` `1` `2` `3` | Mostrar todos los detalles, o solo recursos, servicios o gastos. Otra vez para ocultarlos |
| `Alt`+`B` | Ir al plan de facturación. Otra vez para ocultarlo |
| `Alt`+`A` | Mostrar solo los entregables aprobados, o todos |

## En una lista

Una lista se abre al editar. Escriba para filtrarla. En los grupos de tipología, coincide cualquier parte de la función, el departamento o la empresa. Use `↑` y `↓` para elegir, y `Enter` para seleccionar y bajar.

| Teclas | Qué hacen |
|---|---|
| `Alt`+`↓` | Abrir o cerrar la lista |
| `Ctrl`+`Enter` | En la lista de grupos de tipología, marcar varios. Después, `Enter` los añade todos |
