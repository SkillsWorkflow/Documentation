# Planificación

Una vez que el trabajo existe, hay que planificarlo y asignarle personas. El Gantt sitúa los jobs de un proyecto en una línea de tiempo y define las dependencias entre ellos. El planificador de recursos asigna personas a ese trabajo y muestra quién está sobrecargado o infrautilizado. El tiempo planificado registra cuántas horas se espera que dedique cada persona.
