# Archivos

Archivos es su propia área en el menú principal, respaldada por un sistema de archivos
propio. Está junto a — y es independiente de — la pestaña **Archivos** que tienen documentos
individuales como proyectos, jobs y facturas.

## Disponibilidad

Abrir Archivos necesita el permiso **FilesNavigate**. Ver necesita **FilesRead**, crear
necesita **FilesCreate**, editar necesita **FilesWrite**, y eliminar necesita
**FilesDelete**.

Archivos es una de las áreas que no tiene una definición de lista propia: se accede al área
directamente desde el menú principal.
