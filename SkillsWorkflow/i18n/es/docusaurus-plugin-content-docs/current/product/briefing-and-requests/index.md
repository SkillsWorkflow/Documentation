# Briefing y Solicitudes

Cómo llega el trabajo a la agencia. Un cliente abre una solicitud y, a partir de ahí, esta se convierte en los proyectos y jobs que el equipo entrega.

Para las plantillas que definen lo que se pide al solicitante, consulte [Description Templates](/docs/administration/description-templates) en Administración.
