# Facturación y Costes

La parte económica de la entrega. Las autorizaciones de factura solicitan que se facture a un cliente; las notas de crédito corrigen una factura a la baja. Las órdenes de compra comprometen una compra a un proveedor. Los gastos y las hojas de gastos registran lo que gastó el equipo.
