# Tiempo

El tiempo planificado dice lo que debería ocurrir; las hojas de tiempo registran lo que ocurrió. Esta área cubre rellenar una hoja de tiempo, el cronómetro, mover horas entre proyectos y el circuito de aprobación que sigue una hoja enviada.
